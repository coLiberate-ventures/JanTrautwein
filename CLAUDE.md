# Website Redesign Guidance

## Purpose

This folder contains the working source for the Jan Trautwein website redesign. It is a private design and build workspace. Do not publish from here without explicit approval.

## Copy

Use concise, factual language by default. Do not turn informal voice notes into website copy. Avoid reassurance, filler, abstract framing, and decorative statements. New copy should state what something is, who it is for, and what it does.

## Design

The main website uses a light Stone and bronze system. Use Lora for headings and Manrope for body text. Keep Journey visually distinct, with its established dark adventure treatment.

## Working rules

Preserve existing design versions before material changes. Keep source files and local assets together. Do not modify the live DEPLOY folder during normal redesign work. Never use dashes in prose sentences.
