# Jan Trautwein Website Redesign

This branch stores the October 2026 redesign work before launch.

## Included

`site/` contains the current local website source, design studies, local assets, and the built browser bundle.

`brand/` contains the Stone and bronze visual system.

`CLAUDE.md` records the project guidance and copy direction.

## Local preview

Serve the `site/` directory with a local web server. The current source pages are `index.html`, `coaching.html`, `explore.html`, and `story.html`.

## Publishing

This is a working snapshot. It is not connected to the live site. Publish only through the separate deployment workflow after review.
