# Illustrated testimonial portraits, version 1

These four PNG files are generated style transfer derivatives for the October 2026 coaching website redesign.

Source photos were provided in `AI Website/Client Images Original`. The generation used the supplied monochrome faceted portrait reference as a style guide. Each output is 1254 by 1254 RGBA with a transparent background.

Files are deliberately versioned and do not replace their source photos.

The website currently uses Katie, Sebastian, and Oliver alongside verified existing testimonial copy. Stefanie's portrait is ready but is not paired with a testimonial until Jan selects or approves one.
